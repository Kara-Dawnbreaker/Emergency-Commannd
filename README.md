# Emergency-Commannd

A single-player emergency operations and management simulator featuring a living modern city, realistic emergency services, strategic decision-making and evolving disasters.

## Prototype 0.1

- Small low-poly 3D city district.
- Camera pan and zoom.
- Live incident queue and two fire engines.
- Dispatch units to fires; watch them travel and respond.
- Incident escalation, resolution, pause and speed controls.
- Manual test incident button.

## Run locally

Requires Node.js 20.19+ or 22.12+.

```bash
npm install
npm run dev
```

Production build: `npm run build`.

## Technology
TypeScript, Three.js and Vite. This is an early prototype; visuals, balance and performance will be refined.
